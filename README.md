# İngilizce Tarifler

İngilizce yemek tariflerini Türkçe karşılıklarıyla öğreten içerik sayfaları için prototip.

## Temsilci sayfalar

- Makarna: ana yemek içeriği
- Baklava: tatlı içeriği
- Smoothie: içecek içeriği

## Çalıştırma

```bash
npm install
npm run dev
```

Üretim derlemesi için `npm run build` komutunu kullanın.
